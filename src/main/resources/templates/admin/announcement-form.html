About announcements

  • Public announcements appear in a "General Information" section on the public home page — anyone can see them.
  • Registered members announcements appear as "State Breaking News" on members' own dashboards.
  • Leaving the state blank for a members announcement shows it to every member nationwide; picking a state shows it only to members registered there.
  • Unpublish (uncheck "Published") to hide an announcement without deleting it.
